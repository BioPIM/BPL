
# Unit tests for the BPL

## Build instructions

This project uses CMake, so the build instructions follow standard conventions:
1. `mkdir build`
2. `cd build`
3. `cmake ..`

You can then run `make help` to list all available targets.

## Launching the unit tests

From the `build` directory, you can run the tests with `./test/unit/host/bpl-unittests.host -d y`
