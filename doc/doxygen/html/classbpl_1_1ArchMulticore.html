Detailed Description

Class that provides methods and types for a multi-core architecture.

The main purpose of this class is to provide a 'run' method that will dispatch a task over several threads (according to the object's initialization).

This class also provides the number of process units it can manage. Here, a process unit is a thread.

It also provides some types that can be used within the execution of the task. By default in this implementation, such types will be mainly std containers from the standard library.
