Detailed Description

template<typename ARCH, int MUTEX = 1>
struct bpl::Task< ARCH, MUTEX >

Class that provides runtime information to the end user.

When creating a new task, the developer has the possibility to inherit from bpl::Task in order to get some useful information such as the process unit identifier with the Task::tuid method, or to have access to mutexes when required.

Note this class is optional; if there is not need to get runtime information, the developer should not inherit from it.

Parameters
ARCHthe architecture to be associated to the task
MUTEXnumber of mutexes available to the task.
