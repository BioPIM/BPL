Detailed Description

A TaskUnit object represent a set of units that can execute some task.

It could be in real life a thread (for multicore arch) or a thread (for upmem arch).

A TaskUnit is made of several components, each one representing a set of execution units. For upmem, a component can be a rank or a DPU.

This class is a template one where T is the type of the component (rank or dpu for instance); such a component should know how many exec units it provides; for instance, a dpu is supposed to have 16 tasklets for instance.
